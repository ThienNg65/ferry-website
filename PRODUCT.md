## Platform

web

## Users

Developers, sysadmins, and DevOps engineers on Windows 10 and 11 (64-bit) managing Linux servers, VPS instances, and homelabs over SSH and SFTP—including current WinSCP, PuTTY, MobaXterm, FileZilla, and Termius users.

## Product Purpose

Commercial website (`https://www.ferryssh.com`) for **Ferry**, a Windows SFTP and SSH client that puts dual-pane file transfer, folder sync and compare, an in-app remote file editor, an interactive SSH terminal, live `tail -F` logs, and a server CPU/memory/process monitor in one window.

## Positioning

- **One window instead of four:** Files, SSH terminal, live `tail -F` logs, and server health share one SSH connection.
- **Fast migration:** Import saved hosts, ports, and usernames from WinSCP, PuTTY, and `~/.ssh/config` (passwords are never imported).
- **Runs on your machine:** Free on Windows with Windows DPAPI credential encryption, no cloud accounts, and no telemetry.

## Capabilities and Constraints

- Official distribution channels: Microsoft Store (`9PJPWK568P53`, signed 1-click MSIX) and GitHub Releases (`ThienNg65/ferry-release` for `Ferry-Setup-*.exe` and `Ferry-Portable-*-win-x64.zip`).
- `ThienNg65/ferry` is the private source repository; all public website links for releases, issues, changelog, and licence point to `ThienNg65/ferry-release`.
- Protocols supported: SSH and SFTP only (no FTP, FTPS, SCP, S3, RDP, VNC, or X11).
