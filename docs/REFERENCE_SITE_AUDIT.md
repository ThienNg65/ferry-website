## 2. Eight-Dimension Synthesis

### 2.1 Visual Design
- **Color Palette (Observed):** Light-first institutional clarity: `#ffffff` canvas, `#f8f9fa` / `#eef5fc` muted section bands, deep navy gradient heroes (`#0d1c2e` → `#183c73`), `#183c73` heading navy, `#212529` body slate, `#0374cb` link cyan-blue, and `#278c1b` conversion green exclusively for primary trial CTAs.
- **Typography:** Single-family `Lato` stack (`16px` / `1.5` body; `h1` `40px` / `1.2`, `h2` `32px`, `h3` `24px`, weight `700`). Clean, unpretentious, high readability, though lacks a dedicated display contrast or monospace voice outside code blocks.
- **Visual Signature:** Asymmetric dark-navy card with a large top-right corner radius (`~64px`, see Homepage Data Sovereignty), subtle circuit/network SVG backgrounds, and a curved double-wave SVG bottom edge separating dark hero gradients from white/pale-blue body bands.

### 2.2 Layout Architecture
- **Grid:** Bootstrap 5 (`1320px` container max at `xxl`), generous vertical padding (`48px–96px`), alternating left/right 50/50 split sections on feature pages.
- **5 Distinct Page Templates Identified:**
  1. **Flagship Narrative** (Homepage: hero + logo bar + interactive tabs + 3 pillars + OS stats + 3 plans + testimonial carousel + blog + bottom CTA).
  2. **Product Hub & Feature Deep-Dive** (Curved dark hero + 8-icon anchor strip / TOC card grid + sticky anchor subnav + alternating split sections + dark cross-link matrix).
  3. **Interactive Conversion / Pricing** (Hero + live URL-synced configurator + selectable plan cards + pinned bottom total bar + collapsible sticky-header table + FAQ).
  4. **3-Column Technical Documentation** (Left collapsible tree + center prose/screenshots/code + right sticky "On this page" TOC & feedback widget).
  5. **Editorial & Case Study** (Blog 3-col cards with category filter; 800px article measure with sticky share; Case Study photo hero + overlapping logo + pull quote + 4-card benefits).

### 2.3 Interaction Design
- **Header State Shift:** Transparent over dark gradient hero (`82px`), snapping via `.header-scrolled` to solid `#ffffff` with subtle shadow (`0 2px 8px rgba(0,0,0,0.08)`) past `10px` scroll.
- **Interactive Controls:**
  - *Data Sovereignty Tab Switcher* (Homepage): Vertical tab list on left with active blue dot indicator swaps the dark right-hand card dynamically.
  - *Sticky Anchor Subnav* (Product Overview): Drops down below main header on desktop; collapses into a compact dropdown button (`PROJECT PLANNING v`) on mobile.
  - *Pricing Configurator*: Radio/slider/select controls mutate URL query strings (`?mode=cloud&users=25...`), toggle minimum user floors (`5` vs `25`), switch currency (`€`/`$`), and update a floating bottom calculation bar.
  - *Feature Carousels*: Previous/Next + dot pagination for multi-slide use cases (Work Package Relations, Resource Management, Customer Testimonials).
  - *Docs Copy Buttons & Mobile TOC*: Code blocks include instant copy buttons; mobile docs expose a compact subheader drawer + "Table of contents" accordion.

### 2.4 User Experience & Information Architecture
- **Strengths:** Clear dual-audience routing (Cloud trial vs. Self-hosted Install/Community), zero horizontal overflow (`375.2px` body inside `390px` viewport across every tested page), predictable **text-before-image** mobile stacking regardless of desktop alternation, and scoped omnichannel search (`ALL | DOCS | BLOG | WEBSITE | API | RELEASE NOTES`).
- **Friction / Weaknesses:**
  - *Hero Breadcrumb Omission*: Breadcrumbs live only in the footer on marketing pages (`OpenProject > Product tour > ...`), whereas docs subpages correctly place breadcrumbs at the top of `<main>`.
  - *1200px Navbar Collapse*: Using `.navbar-expand-xl` forces `768px` tablet portrait into the hamburger drawer despite ample horizontal space.
  - *Homepage Initial Paint / Video Fragility*: In headless Chromium at initial capture (`step_2.png`), the Homepage hero gradient/text showed delayed visual paint, and external S3 `<video>` assets (`openproject-docs.s3.eu-central-1.amazonaws.com`) failed with `net::ERR_ABORTED`, falling back to plain text (`Your browser does not support the video tag.`).
  - *96-Card Feature Overload*: The Product Overview page renders 96 `h3` feature cards in one scroll, creating heavy cognitive load if scanned linearly.

### 2.5 Content Strategy
- **Dual-Track Transparency:** Celebrates free/open-source metrics transparently (`17,352` stars, `30M+` downloads, `425` contributors, `120k+` commits, `329` releases) while clearly labeling paid Enterprise tier boundaries with inline plan badges (`Basic`, `Professional`, `Corporate`).
- **Task-Oriented Subheads:** Combines concrete feature names (`h2`: *Gantt charts*, *Task list*) with benefit-driven subheads (`h3`: *Win your team by visualizing your project*).
- **Every Subpage Closes the Loop:** Blog posts, docs guides, case studies, and comparison pages all end or cross-link back to the primary Cloud/On-Premises trial or download funnel.

### 2.6 Conversion & Trust
- **Trust Architecture:** Security & Privacy goes far beyond marketing claims—showing CEO commitment, EU-only hosting, 9 concrete technical controls (bcrypt, AES-256, 2FA, AV scan, session timeouts), public PGP fingerprint, and `security@openproject.com` advisory signup.
- **Accessibility Proof:** `/accessibility/` cites concrete standards (WCAG 2.1 Level AA), independent German Ministry (BMI) audit, GitHub Primer foundation, and a live public backlog link rather than vague pledges.
- **Comparison Honesty:** Dedicated comparison pages and pricing matrices use clear checkmarks, tooltips, and explicit "Available in Community vs. Enterprise" rows.

### 2.7 Technical Quality
- **Observed Performance & Resilience:** Zero console/layout overflow at `1440px`, `768px`, and `390px`; container-level `overflow-x: auto` on code blocks and `.table-responsive` with sticky first columns keep mobile layouts unbroken. External S3 video dependence is a visible single point of failure when blocked or aborted.
- **Dark Mode:** OpenProject's marketing site is strictly light-surface with dark-navy hero/accent bands (no user-selectable dark theme).

### 2.8 Design System
- Bootstrap 5 tokens (`--bs-primary: #183c73`, `--bs-success: #278c1b`, `Lato`), pill buttons (`50rem`), asymmetric rounded dark feature cards, wave SVG transitions, and standardized Enterprise tier badges.
